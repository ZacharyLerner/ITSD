Pay for Print/Campus Printers

Adding Money on RAM Account

If the user is adding money to their RAM account with cash, the money will be useable instantaneously. If the user adds money to their RAM account with their credit card. the process will be delayed and they won't be able to use that money until 2-3 business days later. 

Ink Toner

Finding the toner code for the printer: When you go to refill the toner for a printer, there's a specific code you need to find in the printer to match it up with the actual ink toner. To find which code toner is needed, do the following: Go to the screen of the printer and click on the category that says Supplies. A prompt will come up saying what the printer needs in terms of the toner and paper. For the toner, it will look like "Black Cartridge 14A (CF214A) indicates very low." The CF214A is the code for the ink toner that you need to look up at the Service Desk from the toner supply boxes, and this code will vary from printer to printer. Once you find the appropriate ink toner box, replace the toner at the printer.

Replacing the ink toner: Each toner cartridge has a little circular orange shield on it on one side of the toner, as well as a plastic film in the middle of the toner that has to be removed from the cartridge or else it will NOT print properly. When removing the little circular orange shield but breaking off the orange shield, just note that a long plastic strip will come out from inside the toner. Closest demonstration video is this: https://youtu.be/WgNAddwHlNs. P.S Advice - don't wear a white shirt when doing this.

Getting more ink toner: Contact Mark Oliver by email to request more ink toner if none is available at the service desk.

Refilling the Printer Paper

If there's an error message saying "Low on Paper," check each drawer and refill them with printer paper. There is usually stacks of printer paper next to the printers themselves.

Printer is Jammed

For jammed printer issues, there will be instructions on the little screen on the printer itself with a walkthrough of how to fix the jam. If you're unable to solve the issue, let a TL or FTS know. 

Payment Refunds for Bad Printing

All payment refund questions should be redirected to Mark Oliver. Create a ticket with the user's URI ID Number, name, the toner type they used (black and white OR color), the number of pages they printed, and the refund amount. Classify the ticket as Pay for Print --> Submit Printer System Issue, which should automatically assign it to Tier 2 Support.

Specific Issues

Billing Error

If you receive a "Insufficient Funds" error when swiping your card, it can mean either of the following:

  • Check if there is enough money on the RAM card. The error usually means that you don't have enough money in your RAM account to print. Once you add funds to your RAM account with a credit card, it can take up to 3 business days for the money to actually transfer. If you use cash to add money to your RAM account, the funds will be added instantaneously:

    • Adding Funds to RAM account: https://web.uri.edu/dining/ramaccount/

  • It might also be the case that your card has been deactivated for some reason. This can happen if your graduation date changes, or you took a semester off. Go to the ID office in the Memorial Union and have them re-activate the Ram account.

  • The magstripe on the card itself might be corrupted (the black stripe at the back of the card may appear light). Exchange the card for a new one at the ID office in the Memorial Union - replacing a worn out or expired card is free to replace as long as you bring the he old card with you.

Error During Software Installation

If you receive an error such as "Software Installation Error" or the ID Number popup doesn't appear when trying to print from the device, you need to redo the whole process of adding the printers to the device. Make sure to delete/remove the corrupted printer from the list, and restart from the beginning.

Printer asks for a “password” after swiping your card

This happens when the magnetic stripe is not read correctly. The user can attempt to swipe again, or retrieve a replacement card from the ID office in the Memorial Union: https://web.uri.edu/campusid/idcard/.

Scanning

P4P printers do not have the option to scan doucments, despite the option existing on the printer, if a user comes down to ask for assistance inform them to use a pdf scanner on thier phone. 

P4P Software Won't Download?

If the software won't download at all and you have tried different browsers to no avail, please try opening the actual download links here in an incognito window. If that doesn't work and you're greeted with a blank page in that incognito window, either refresh that page or copy the link, open a new blank incognito window, and paste it in there. It should now download.


  • For example, on that page, right click on the "URI_P4P_BW_Sept2024" download link, and click on "Open in Incognito Window".

  • An empty incognito should open up with a "http://labprint.uri.edu/Uniprint/URI_P4P_BW_Sept2024_for_Lte.exe" link.

  • If the page is blank AND a download doesn't start, copy the link in the page, open a new empty incognito window, and finally paste & enter the link in the search box. It should now trigger the download.

General Printers

Troubleshooting

  • Restart the printer & computer

  • Check the printer for errors - no paper/ink/toner

  • Plugged in correctly

  • Remove/add the printer from the computer 

  • Uninstall printer drivers & reinstall

  • Restart printer spooler

  • In cmd prompt: ping IP Address (checks and confirms if the computer is connecting to the printer)

Windows Troubleshooting

Use the Windows Printer Troubleshooter

  1. Open Settings and click Update & Security

  2. Select Troubleshoot and click on the option that says Printers (you might need to click Additional troubleshooters and then select Printer)

  3. Click the Run the troubleshooter button

  4. Choose the printer that needs fixing and click Next to go through the troubleshooter

Error: Some or all property page may not be displayed - Word

Delete the printer from Control Panel --> Printers. Reinstall the printer. If this doesn't work, delete the printer, delete the cached copies of the printer drivers, reinstall the printer

How to Delete Cached Copies of all Printer Drivers

If this is a possibility, it's easier to delete the cached copies for ALL installed printers: Make a list of all the installed printers and their names (if they live on a print server). 

  1. Go inside Control Panel --> Hardware and Sound --> Devices and Printers

  2. Right click on the printers and select Remove Device (Do this for all the printers)

  3. Hold down Windows key + R for the Run App --> Type in services.msc 

  4. Stop Print Spooler

  5. Back up the whole folder c:\windows\system32\spool\ 

  6. Go inside c:\windows\system32\spool\drivers\w32x86 and delete everything there

  7. Hold down Windows key + R for the Run App --> Type in services.msc 

  8. Start Print Spooler 

  9. Reinstall the printers

How to Delete the cached drivers for HP specific printers

  1. Go inside Control Panel --> Hardware and Sound --> Devices and Printers

  2. Right click on the HP printer and select Remove Device

  3. Hold down Windows key + R for the Run App --> Type in services.msc 

  4. Stop Print Spooler

  5. Back up the whole folder c:\windows\system32\spool\ 

  6. Go inside c:\windows\system32\spool\drivers\w32x86 and delete all files that begin with "HP" (this was an HP printer)

  7. Hold down Windows key + R for the Run App --> Type in services.msc 

  8. Start Print Spooler 

  9. Reinstall the printers

How to Delete the Cached Drivers for a Specific Printer other than an HP

You need to know the names of the driver files. Sometimes you can get the names of the driver files before deleting the printer:

  1. Go inside Control Panel --> Hardware and Sound --> Devices and Printers

  2. Right click on the HP printer and select Properties

  3. From Properties --> select the About tab/Device tab/Drivers tab

Then, follow the same process as How to Delete the cached drivers for HP specific printers above

Print Spooler (spoolsv.exe) uses 100% of CPU

If the computer is running slow, check the CPU to see what's taking up the CPU resources. Check to see if it's the spoolsv.exe that might be using most of the CPU resources.  It's probably due to the print jobs that spooled which need to be cleared.  If it cannot delete jobs, or jobs may be queued by another user of the computer, try the following:

  1. Hold down Windows key + R for the Run App --> Type in services.msc 

  2. Stop Print Spooler

  3. In cmd.exe, type:

    1. del /f /s /q %temp%

    2. del /f /s /q c:\temp

    3. del /f /s /q c:\windows\temp

    4. del /f /s /q c:\windows\system32\spool\printers\*.*

Printer not showing in Adobe Reader

  • Make sure that the user has downloaded and runs the latest version of Acrobat

  • Repair the Adobe Acrobat installation

    1. Launch the Adobe Acrobat Reader app on the computer

    2. Click on Help from the horizontal categories at the top 

    3. Select Repair Installation

    4. In the new Dialog box, click Yes for the Are you sure you want to repair the current installation message

    5. Adobe Reader will initiate the repair process which might take some time, so wait till it is completed

    6. Once the repair process is complete, close the app and launch Adobe Reader again

  • Update Printer driver

  • Run the Windows Printer Troubleshooter

  • Set the printer as default

Clear the Print Queue with the Command Prompt

  1. Launch Command Prompt

  2. Type net stop spooler into the Command Prompt and press Enter to switch the print spooler off

  3. Next, enter del %systemroot%System32spoolprinters* /Q into the Command Prompt and hit the Enter key. That will erase the stuck printer queue

  4. Input Net Start Spooler to restart the printer spooler

  5. Turn the printer on and start printing

Getting Static IP Address

A static IP addres means that it stays the same IP overtime. It prevents printeres from being flagged by IT Security. Only Faculty and staff can request them. 

In order for users to connect their printers without a wire, they can request to have a static IP address assigned to the printer. If it's a department printer and they want to be able to print via wi-fi, they would have to request a static IP address. When creating the ticket, include the printer name, printer type, and IP address. It would go to ITS Infrastructure Networking. Static IP Addresses always start with 10.xxxxxxx.


Adding a Printer with Static IP

For Windows 10:

  1. Click the Windows button in the lower left corner

  2. Open Settings 

  3. Click Devices

  4. Select Printers & Scanners

  5. Click Add a printer or scanner and wait for a few seconds until the option to Add a printer that wasn’t listed appears. Click it

  6. Choose the one that says Add a printer using a TCP/IP address or hostname

  7. Click Next in the next window, then input the static IP address that was given by Tier 2 into where it says to input your Hostname or IP Address

  8. If done successfully, it should come up with a screen saying you have successfully done the process

  9. After that, a final screen stating you have finished adding a printer will appear. It will give you an option to print a test page to see if you are able to print to the printer. It's recommended that you do this to see if it will work.

Printing on VPN (Cisco AnyConnect)

You have to enable Split Tunneling, more information can be found here: Split Tunneling Feature (uri.edu).

Double-Sided Printing for Big Sur and Above

You need to enable Duplex Unit if the double sided printing is not appearing when attempting to print. In order to do so, do the following: System Preferences > Printers & Scanners > Select the printer that you're printing to (like URIColor or URIB&W) > Options & Supplies > Options > Enable Duplex Unit

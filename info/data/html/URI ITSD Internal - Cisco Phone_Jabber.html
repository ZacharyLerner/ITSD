Call Forwarding with Self-Care Portal

The VOIP (Voice Over Internet Protocol) Self-Care Portal is a portal for Cisco Desk Phones to set up forwarding and control your URI telephone features such as voicemail and speed dial. It can be accessed by anyone that has a Cisco phone, and can be accessed using the following methods below, with their SSO account:

On Mac

  • Open the Jabber application --> Click Jabber from the top bar next to the Apple icon --> Click Preferences --> Click Self-Care --> Click the Open Self Care button

  • Alternatively, you can click on the self-care portal link at the bottom of https://its.uri.edu/services/945d4ec71aa35e3332cf0644159292c18096d90d8d/setting-up-voicemail/ to get to online version of the Self-Care Portal

On All Other Devices

  • You can click on the self-care portal link at the bottom of https://its.uri.edu/services/945d4ec71aa35e3332cf0644159292c18096d90d8d/setting-up-voicemail/ to get to online version of the Self-Care Portal

Webex Phones

go to https://settings.webex.com/profile > webex calling > call settings > turn on call forwarding 

here you can set it to go to a personal cell number as well as control other settings for call forwarding such as send to voicemail, when busy (If call waiting is enabled, up to four calls may be received before call forwarding busy is triggered), when no answer, when not reachable (If your Webex Calling primary line is inaccessible, you can forward incoming calls to a personal phone number. If you are signed in to the Webex mobile app, your Webex Calling primary line is considered accessible), and enable ring reminder on your cisco phone. 

Voicemail Forwarding with Email

Call forwarding can be setup so that voicemails get sent to the user's URI email address (think of the Service Desk's voicemail system - it's set up so that the voicemails get forwarded to the URI SD email).

All Devices 

  • Verify the user's URI Cisco phone number matches with the one listed in the URI Directory

  • Create a ticket that includes the user's URI Cisco phone number and URI email address

  • Ticket should automatically get assigned to the TS Telecom team.

Setting up Voicemail with Phone

In order to self-reset the vociemail pin, or set it up after having the pin reset: Setting up Voicemail PDF (Voicemail Commands)

  1. At the user's own phone, press the Messages button.

  2. When prompted, enter the following PIN followed by the # key: 111597#

  3. Follow instructions to record the user's name.

  4. Follow instructions to record the user's greeting.

  5. Follow instructions to change the PIN the user entered above to something easy for them to remember. A minimum of 4 characters is required. Before the user hangs up for setting up their voicemail, be sure they wait until they hear: “You have finished enrollment.”

Listening to Voicemails

Call from your desk:

  1. Press the messages button

  2. Enter PIN then the # key

To call voicemail from an outside line: 

  1. Dial 401-874-9800 or dial your office phone number (wait until you hear your greeting)

  2. Press * 

  3. When asked to enter your ID, enter your five digit extension number (last five digits of your campus phone number) then the # key

  4. Enter PIN then the # key

See Voicemail Commands For More Information

Webex:

Change Phone Name from a Previous User

When receiving calls on a Cisco phone, the display on the phone will display the name of the individual associated with the number in the directory. If an individual is to take over a number from someone else (for whatever circumstances) then they would most likely like to have the name changed to theirs. To do this:

First check that their name matches the Cisco Phone number they are trying to get the name changed on in the directory.

If so, then create a ticket that includes:

    • Phone number of the Cisco phone

    • Phone location (Building and Room #)

    • Reason

    • User contact information

  • Ticket should be assigned to the ITS Telecom team.

User Forgot Voicemail PIN

If a user calls stating that they forgot their PIN to their Cisco phone, in order to help resolve this issue we:

Create a ticket that includes:

  • Phone number of the Cisco phone

  • Phone location (Building and Room #)

  • Reason

  • User contact information

  • Ticket should be assigned to the ITS Telecom team.

If a user calls stating that they forgot their PIN to their Cisco Webex phone, in order to help resolve this issue we:

  • Direct the user to sign in to https://settings.webex.com/profile

Cost Charges

On the Cisco Office phones, departments/people get charged based outgoing calls (if a URI office phone calls out) - not incoming calls (if an outsider calls in).

Phone Number Extensions for URI, Non-URI & International Calls

URI Numbers

Kingston Campus

URI Kingston Campus numbers can be contacted by just dialing the last 5 digits of the number. To determine if the number is a URI Kingston number, it always follows the format 401-874-xxxx. An example of dialing a Kingston Campus number: 4-9500.

Providence Campus 

URI Providence Campus numbers can be contacted by just dialing the last 5 digits of the number. To determine if the number is a URI Providence number, it always follows the format 401-277-xxxx. An example of dialing a Providence Campus number: 7-5000.

Non-URI Numbers - USA

For non-URI USA numbers, dial 91 at the beginning of the entire number. An example of dialing non-URI USA numbers: 91-(347)764-3210 (the hyphens aren't included, these are just included to represent the different parts)

Non-URI Numbers - International Numbers (Dialing out to other Countries)

For non-USA numbers, dial 9 + 011 + country code + city code (if applicable) + local number. An example of dialing non-USA numbers: 9-011-880-1-83431000 (the hyphens aren't included, these are just included to represent the different parts).

Cisco Jabber

General Information

Jabber is an online service that URI employs to URI Faculty and Staff with a Cisco Phone. This service allows its users to access their Cisco phone through an app via their SSO credentials. This app is available for iPhone, Android, Mac, and Windows. Faculty and Staff are only able to have Jabber if they have a URI Cisco Phone, and their number matches the number associated with them in the directory.

If a user does not have their number listed on the directory, direct them to 「e-Campus → Self Service → URI Directory Profile 」 to edit their campus phone.

IMPORTANT: Jabber CANNOT be used with a departmental phone. It can only be used with a URI phone number that is displayed in the directory for only one person.

Requesting Jabber

As we are moving to Webex phones, users should no longer be added to Jabber, if someone contacts us regarding this, we make a ticket to ITS Telecom stating that they need a consult to see if Webex phones or Jabber would be compatible for the user.

Specific Issue

Can't install CA certificate - This certificate from null must be installed in settings; CA certificates can put your privacy at risk and must be installed in Settings

  • Go through Android Manual Config instructions

  • Need to enable CA certificates to be installed:

    1. Open Device Settings

    2. Go to Security or Biometrics and Security (depends on device)

    3. Go to Encryption & Credentials or Other Security Settings (depends on device)

    4. Go to Install from storage or Install a certificate (depend on devices)

    5. Select CA Certificate from the list of types available

    6. Accept a warning alert

    7. Browse to the certificate file on the device and open it

    8. Confirm the certificate install

    9. Return to the screen that has the list of types available (step 5) and select WiFi

    10. Accept a warning alert

    11. Browse to the certificate file on the device and open it

    12. Confirm the certificate install

  • When prompted to insert text for Add the Domain, insert uri.edu

Device Enrolling Android

In Android 10, there's a setting that allows users to have a randomized MAC address that allows users to mask their MAC address. If you ever need to enroll one of these devices to the wi-fi, please ensure that this setting is turned off for URI_Open: 

Settings --> Connections --> Wi-Fi --> Click the settings gear next to the name of the Wi-Fi --> Advanced --> MAC address type --> Select Phone MAC instead of Randomized MAC

Cloudpath Cutoff

  • MacOS version 10.12 (Sierra) is now the cutoff point for Cloudpath and is no longer supported. If it's determined that the user has 10.12 (Sierra) or older, it needs to be device enrolled in order to connect to the URI Wi-Fi. Alternatively, users with this version will need to update their OS if they want to connect to URI_Secure.

Automatically switched to URI_Open while connected to URI_Secure

  • Shift URI_Open to be below URI_Secure in the Wi-Fi list: Wi-Fi list --> Open Network Preferences --> Advanced --> Wi-Fi --> Drag URI_Secure above URI_Open --> Ok

  • Delete URI_Open from the Wi-Fi list: Wi-Fi list --> Open Network Preferences --> Advanced --> Wi-Fi --> Select URI_Open --> Click the minus button --> Ok

Error in Safari "Unable to Connect to Server"

  • Uncheck all boxes under Proxy: Wi-Fi list --> Open Network Preferences --> Advanced --> Proxies --> Uncheck all boxes (especially SOCKS Proxy, Web Proxy (HTTP) and Secure Web Proxy (HTTPS))

M1 Macbooks/Big Sur URI_Secure Issues OR Error: We were unable to write the configuration system to the operating system

 If a user has a new Macbook (the M1 Macbooks) or has Big Sur, and the Mac download does not work for the user when trying to connect to URI_Secure, have them use the iPad download (mobile authentication for URI_Secure that downloads the PEAP certificate).

Windows

Cloudpath Certificate won't Install

If URI secure won't install cloudpath onto the Windows machine (i.e = infinite loops or does the "select a certificate thing"), you can delete the certificates from the windows certificate manager. To get to the Windows Certificate Manager: Windows Search bar > Type certmgr for Manage ccomputer certificates to pop up & click it > Personal > Certificates > Select the certificate and click the red X on the top of that screen to delete it.

This can happen due to "smart screen" in the browser settings, turn off the scart screen and the antivirus temporarily in order to download and then turn it back on for the user.

S-Mode on Windows

How to remove S-Mode from a PC without the URI email logged in as the Microsoft account
To switch out of S-Mode in windows 10 or 11, go to Settings > Update and Security > Activation. 

More clear instructions:

  1. Go to the Microsoft store

  2. Type in the search bar S Mode, BUT DO NOT HIT ENTER TO ACTUALLY SEARCH THIS!

  3. From the search recommendations, one of them will say S Mode - click on this

  4. You should now be on a page that says: "Switch out of S Mode"

  5. You are going to click on  the Get button and allow the PC to run it's course a couple of seconds. If you followed these steps correctly, S-Mode should be removed from the PC.

How to get device that is in S mode on to campus wifi?

  1. Ensure ethernet connectivity and remove S mode as shown in the previous steps

  2. Disconnect from ethernet and follow the normal WiFi setup process.

Network Icon Disappeared from Windows

If the Network/Wifi icon that you'd use to connect to the wifi has disappeared from settings, then try the following solution: 

  1. Device Manager

  2. Navigated to the network driver that has an error symbol

  3. Look up that specific driver in Google 

  4. Downloaded the driver 

  5. Restart the machine

  6. The wifi symbol should now appear and you should be able to successfully connect to the wifi

Eduroam

What is eduroam?

eduroam is a global wireless network access service for education. They provide users (students, researchers, staff and faculty) with wireless access at participating institutions through the use of their home institution credentials (home = where you are enrolled in study or are employed).
What that means for you if you visit an eduroam school or facility is that you can easily use your URI WiFi credentials (SSO) on their network.  Whether you’re moving across campus or spending time studying or working at another research and education institution, eduroam gives you seamless internet connectivity.
What that means for someone from a different eduroam school or facility were to come to URI, they can use their own institution's WiFi credentials to get into URI_Secure.

How to Setup eduroam

  1. Go to https://cat.eduroam.org/ and click the big blue button that says Click here to download your eduroam installer

  2. A popup will appear on that same screen, asking you to choose your home institute. Look for the institution that the user is currently enrolled in or are employed at, and select it

  3. Click the Download your installer blue button for your device to download the installer (this will work for Android, iOS, Mac, Windows, Linux, and Chrome OS)

  4. Open the downloaded installer and click through the instructions until you get to the screen that says User credentials

    1. The user must enter their own institution's WiFi credentials

  5. Click Next to allow eduroam to finish installing 

  6. Once eduroam's application is installed, go to Networks and look for the WiFi name eduroam (the user will NOT be connecting to URI_Secure nor URI_Open)

  7. Select the WiFi name eduroam from the list of networks available

  8. The user should now be able to successfully use the internet

Routers distribute IP addresses and access points boost the signal strength of the Wifi

Brookside Hall AP + Port Activation

We cannot activate the ports that are near the AP's for user connectivity.  There is only the port in the common area that is supposed to be activated for this purpose.  We have received many tickets to activate the secondary port for the AP but will be using that port for the AP in the future. We recommend anyone living in Brookside that needs a port get a really long ethernet cord with a splitter. 

Dorm Rooms

By default, the lights are turned off on Wireless Access Points (WAPs) in dorm rooms. The lights were distracting for students, per multiple students/parents. This has been a common practice for at least two years, and the SD has been reminded of this several times. If a student calls in to report their AP is not working because the lights are out, the SD tech should ask questions to determine if the student(s) are receiving Wi-Fi coverage. If they are, there is no issue to report and the ticket should be closed as information only. If the student reports an issue with coverage, a Quest should be set up to test reception at the location. If there is an issue, then the ticket can be escalated and speeds should be recorded.  


Account Types

Student/Staff/Faculty - when any active member of URI is connecting their devices to URI_Secure. These accounts have no restrictions on them.

Sponsored Guest - when a visitor at the university is going to be on campus for an extended period of time and needs access to URI websites (e.g. some contractors, guest lecturers, etc.). Users need to request these accounts, and the account usually only lasts for one week

Restricted Guest - When someone not affiliated with the university just needs basic internet access (e.g. student’s parent just needs to access their email). These accounts can’t access URI websites and the access is very temporary.

Rouge Router

A Rogue Router (or a Rogue DHCP server) is a wired or wireless router connected to the URI network that is not explicitly authorized by IT Services. When a rogue router is connected to the URI network, it poses a security risk. Rogue routers do not require user authentication and may allow a virus-infected and/or malicious machine to join the network. An incorrectly configured router can  cause interruption in connectivity to computers on the same subnet.

Issues

After students take an exam, the software locks their computer. This makes them unable to do anything on the computer (even after rebooting), including boot into safe mode and the bios menu.

If you can get into safe mode on a Windows machine, there is a fix, which involves using command prompt to restore the computer. However, there is no such fix for Macs, other than reformatting the computer.

The error comes down to conflicts with antivirus software, in that it conflicts with Examplify when it is running in the background during an exam. Examplify tries to shut down any part of the computer that connects to the network, so if the antivirus tries to do this, the two programs conflict with each other.

Windows Defender and Malwarebytes are compatible with ExamSoft. Kaspersky and McAfee are not compatible. Other anti-viruses like Avast and AVG are known to cause problems with ExamSoft.

Sometimes if the OS is updated, it becomes incompatible with ExamSoft.

Other common issues with ExamSoft include but are not limited to: black screens, missing power options, missing task manager, and inability to connect to WiFi.

What students should know

  1. Make sure the computer is virus free and fully updated

  2. Ensure the computer meets the system minimum requirements

  3. Ensure the computers date and time are accurately set

  4. Make sure the computer's antivirus is turned off before taking an exam

  5. Close out all programs besides ExamSoft before an exam

  6. Make sure your computer has the correct date and time

  7. Disable the sleep/hibernate mode on your computer

  8. Don’t upgrade your OS right after it is released

If the student has been having lots of issues with ExamSoft and they don’t want to install it on their personal machines, they can talk to Ian Lester about getting access to the loaner laptops. However, due to the limited amount of loaner laptops, this option is not available for everyone.

Hardware Token

Hardware vs Software

Hardware token is a small physical button device that generates a single-use code to use when accessing a platform. A software token is a software that is installed on a user's device (for example DUO is a software token).

Requesting a Token

These are only given to people that have no phones, tablets, or accessible landlines or have certain circumstances where an exception is allowed. A ticket needs to be created: Basic Info, contact info, department the user is part of, and verify that the user’s manager/head of department has confirmed the request for a hardware token (we need to receive an email from their manager/head). 

Pick Up Process

When the user is at the desk, you check their ID card and confirm their identity.

After verifying identity, you proceed to talk to a full time staff who should handle the next part. 

They will go grab the hardware token from the empty desk we have next to the GA desk and they will have to validate it in order for the hardware token to work. 

The hardware token gets handed to the user and they should be all set and on their way.

McAfee

TO CLARIFY: URI does NOT provide McAfee !


What is McAfee ?

  • popular antivirus software programs offering robust protection against a range of malware, including viruses, spyware, adware and ransomware.

Does URI generally encourage the use of McAfee ?

  • No, McAfee interferes with most programs that URI offers. In certain cases it actually hinders the ability to connect to URI Secure.


How do you uninstall McAfee from a Windows machine? What if McAfee is in managed mode?

    • To uninstall McAfee go to Add/remove programs → find McAfee programs → uninstall each program. You will need to uninstall every other program before you uninstall the McAfee Agent.

    • You can also use the McAfee removal tool.

    • If McAfee is in managed mode you will need to locate the FrmInst.exe file on the computer, navigate to it in command prompt and run a command with it. 

      •  cd C:\Program Files (x86)\McAfee\Common Framework

      • Frminst.exe /remove=agent


If McAfee is not fully removed when uninstalling, what would you do to fully remove it / what programs you can use and where you can check to completely remove it. ? 

  • Use McAfee’s Product Removal Tool or Revo Uninstaller (which can be found on HD Tools USB). Check under the McAfee folder in Program Files/Program Files (x86) to make sure all files have been removed. Check Task Manager to make sure all McAfee processes have been stopped. If everything fails, reformat the computer. DO NOT TRY TO REMOVE MCAFEE MANUALLY. 


A user was flagged by our IT security team for having illegal programs installed on their device. What could be the consequences this user may face if they do not resolve the issue ?

  • They can lose connection to the URI wireless networks

  • If there are multiple infractions in regards to this policy being broken, we might have to completely reformat the user’s machine and they will not be able to save or restore ANY of their data.

Qualtrics

Access to Qualtrics

As of August, 2022 Qualtrics is now auto-enrolled. Users can access Qualtrics from the Office Portal without having to request access.

System Unavailable Error

If user's receive a system unavailable error, go through the basic troubleshooting steps. If that doesn't resolve it, then create a ticket for ITS Research Computing so that it can be assigned to Christian Vye.

Locked Out Of Account

If a user has tried to log into Qualtrics too many times with incorrect credentials, they will be locked out of their account. A ticket to ITS Research Computing needs to be made to unlock the account.

College of Business

The URI College of Business had a separate Qualtrics license previously, where they would bypass SSO and log in right through qualtrics.com. This is no longer available but if there are accounts that need to transfer projects/other work from their old Qualtrics account to their URI SSO Qualtrics account, a ticket can be made to ITS Research Computing. If their Qualtrics username is of the form: EcampusID@uri.edu or EcampusID@uri.edu#uri, they will not need migration.

Multiple Accounts

In the case of someone using an email to log into Qualtrics that is not recognized, even though the user has Qualtrics access, make sure they are using their full URI email because some people had multiple accounts (other, usually shortened versions, of their account). For example, Christian Vye has his URI email christianvye@uri.edu , but he also had a previous account, cvye@uri.edu, that is no longer valid to log in with. In the case that migration needs to be done from their old accounts to their URI SSO account, a ticket can be made to ITS Research Computing to migrate the data.

Searchmarquis Browser Hijacker

Searchmarquis is a virus that targets browsers, and is mostly specific to MACs. Basically you want to remove "Searchmarquis" from all the browsers:

  1. Safari: Preferences > Search > Disable "Enable Quick Website Search"

  2. Chrome: Settings > Search Engine > Delete all under Site Search > go back to Search Engine > Edit default Google link to: http://google.com/search?q=%s

Note: It is recommended to restore your browser to original settings after performing the steps above. It is also worth mentioning that this may carry over in chrome profiles.

TAP by Proofpoint

TAP scans incoming emails for known malicious hyperlinks and for attachments containing malware. TAP works behind the scenes, which means you do not need to do anything to activate or take advantage of the system.

TAP scans any/all URLs in an email and rewrites them as Proofpoint URLs. PRoofpoint URLs allow Proofpoint to check the destination site is considered safe, and that the link will function normally. If the destination site is compromised, the site will be blocked. If you click a link it will function normally. If the destination site is compromised, the site will be blocked. If you click a link to a blocked site, you will be redirected to a page on the Proofpoint website, which will explain why the site has been blocked.  

TAP scans all of an email's attachments for known malicious files and URLs, however, TAP does not rewrite URLs in email attachments. If it detects a malicious URL in attachments or the attachment is a malicious file, it will block the attachment. TAP only scans emails received by URI accounts. 

IF a user gets an email about one of their emails being in quarantine from proofpoint-pps@ppops.net this means that TAP detected something suspicious and quarantined the emails as a security precaution. The user can click on the link in the email and the user can review the email and either allow or deny them. 

Link: https://security.uri.edu/targeted-attack-protection-tap/

WebEx Labs

WebEx Labs is a software that can be used to request an appointment to remotely access on-campus lab computers.

Some students are coming in asking to get Windows on their Macs because they need an application called Geometrics. They can reserve a virtual Windows computer on WebEx labs. The KB article on how exactly to do that is here: https://kb-interim.its.uri.edu/entry/99/. I would not recommend trying to install another OS onto a device over zoom/phone.

An important note is that any files saved on the lab computer will not save locally past the point you reserve the computer. To save your files you should store all files in the cloud (Google Drive or email them to yourself).

At the end of the reserved time, it will kick you out with a 15-minute warning.
